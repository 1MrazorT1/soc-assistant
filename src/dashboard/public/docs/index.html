SOC Assistant Documentation

AI‑Powered Threat Intelligence Aggregation Platform

Aggregate, analyze, and visualize Cyber Threat Intelligence (CTI) from MISP, AlienVault OTX, NVD, URLHaus, VirusTotal and more. Extract valuable data with NLP and alert analysts.

  • Version: 2.0
  • Author: Med Toujani
  • Repo: soc-assistant
  • Created: 2025-08-06
  • Updated: 2025-08-11

Architecture

The platform is composed of:

  • Data Collectors – Python scripts/APIs (MISP, OTX, NVD, URLHaus, VirusTotal, AbuseIPDB).
  • NLP Service – spaCy NER model trained on CTI to extract IOCs, CVEs, actors, etc.
  • Backend API – Flask endpoints to serve collected/enriched data.
  • Storage – Local (soon will be changed to MongoDB).
  • Dashboard – React UI for events, CVEs, malicious URLs, and on‑demand VT checks.
  • Alerting – Email through SMTP (Simple Mail Transfer Protocol).

Key Features

  • Scheduled fetch from CTI sources and normalization.
  • spaCy NER extraction for IP, DOMAIN, URL, HASH, CVE, ACTOR.
  • MITRE ATT&CK tagging (planned).
  • Interactive dashboard (React) + REST API (Flask).
  • Custom alert rules (severity, source, tag).

Installation

Follow these steps to set up the project locally.

Prerequisites

  • OS: Linux/Windows/Mac
  • Python 3.10–3.12, pip, virtualenv
  • Node.js 16+ and npm
  • API keys : MISP, OTX, VirusTotal, AbuseIPDB

Environment Variables

# .env (project root)
# MISP config
MISP_URL = https://<your-misp>
MISP_API_KEY = <key>
MISP_SSL_VERIFY = false

# ALIENVAULT config
OTX_API_KEY = <key>

# VirusTotal config
VT_API_KEY = <key>
BASE_URL = https://www.virustotal.com/api/v3

# AbuseIPDB config
ABUSEIPDB_KEY=<key>

# NVD config
NVD_API_KEY = <key>

# Twitter config
TWITTER_BEARER_TOKEN=<key>

# Malshare config
Malshare_URL = https://malshare.com/api.php?api_key=<key>=getlist
Malshare_KEY = <key>

# Alerting Email config
ALERT_EMAIL = <email address>
ALERT_PASS = <key>
ALERT_TO = <receiver's address>

Setup

# 1) Installation
python3 -m venv soc_env
source soc_env/bin/activate
git clone git@github.com:1MrazorT1/soc-assistant.git
cd soc-assistant/
pip install -r requirements.txt

# 2) Starting Backend
python fetch_all.py
python launch.py 

# 3) Starting the Dashboard
cd src/dashboard
npm install
npm start

If you see a Webpack OpenSSL error (error:0308010C), use Node 18 LTS or set NODE_OPTIONS=--openssl-legacy-provider for dev.

Usage

Start collectors, then explore data from the dashboard.

Run Services

# One-shot collectors
python src/data_collection/misp/fetch_misp.py
python src/data_collection/otx/fetch_otx.py
python src/data_collection/nvd/fetch_nvd.py

# Scheduler (periodic fetch)
python src/fetch_all.py

Dashboard Navigation

  • /events – Events / IOCs
  • /cves – CVE list & details
  • /malicious-urls – Aggregated URLHaus, OTX, etc.
  • /vt-check – Submit a URL/IP/hash and view VirusTotal details

Data Processing Pipeline

  1. Collect JSON/CSV feeds via APIs or RSS.
  2. Normalize fields (timestamp, source, type, confidence).
  3. NLP Enrichment via spaCy NER for IOCs/CVEs/actors.
  4. Persist to MongoDB/Elasticsearch. (Planned)
  5. Serve via Flask API to the React dashboard.
  6. Alert via email.

REST API

Base URL (dev): http://127.0.0.1:5000/api

Security Considerations

  • Secrets: never hardcode API keys. Use .env and a secrets manager in prod.
  • HTTPS: validate TLS certificates for external APIs; pin where possible.
  • Access Control: restrict dashboard/API with auth proxy or JWT (planned).
  • Rate Limits: respect third‑party API quotas; exponential backoff in collectors.

Troubleshooting

MISP 403 Authentication failed

Ensure MISP_API_KEY belongs to an API‑enabled user and sent in the Authorization header. Verify server URL/SSL.

Webpack OpenSSL error

Use Node 18 LTS or set NODE_OPTIONS=--openssl-legacy-provider for development only.

spaCy model not found

Check NLP_MODEL_PATH and that model-best exists. Retrain or copy models accordingly.
